# CodeAlpha Internship Projects



This repository contains the projects completed as part of my CodeAlpha internship.



Each task is organized in its own directory, with separate source code, documentation, and setup instructions.



## Projects



### Task 1 - Simple E-Commerce Store



**Project: MarketHub - Full-Stack E-Commerce Platform**



A full-stack e-commerce application featuring customer authentication, product browsing, shopping cart, checkout, Razorpay payment integration, vendor management, administration, and delivery tracking.



**Technology Stack:**

- Frontend: Next.js, React, TypeScript, Tailwind CSS

- Backend: NestJS, Node.js

- Database: PostgreSQL

- ORM: Prisma

- Authentication: JWT and bcrypt

- Payments: Razorpay
