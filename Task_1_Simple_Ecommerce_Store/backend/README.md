# MarketHub Backend

This directory contains the backend API for MarketHub, a full-stack e-commerce platform.

## Technology Stack

- Node.js
- NestJS 12
- TypeScript
- PostgreSQL
- Prisma ORM 7
- JWT Authentication
- bcrypt
- Razorpay

## Backend Modules

- Authentication
- Products
- Vendors
- Orders
- Payments
- Administration
- Delivery Management
- Database Integration
